Student Grade Tracker

About

Student Grade Tracker is a Java console-based application developed for the CodeAlpha Java Programming internship task.

Features

- Add student details and marks.
- Calculate each student's average marks.
- Display the highest and lowest marks.
- Calculate the class average.
- Validate marks between 0 and 100.
- View a student grade report.

Technologies Used

- Java
- ArrayList
- Object-Oriented Programming
- Visual Studio Code

How to Run

1. Install Java JDK.
2. Open the project in Visual Studio Code.
3. Compile the program:
   "javac StudentGradeTracker.java"
4. Run the program:
   "java StudentGradeTracker"
